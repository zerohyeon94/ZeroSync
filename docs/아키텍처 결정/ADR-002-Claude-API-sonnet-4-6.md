# ADR-002 — AI 엔진으로 Claude API 선택 (claude-sonnet-4-6)

> 날짜: 2026-04-28 | 상태: 확정

---

## 결정

AI 엔진으로 **Anthropic Claude API (claude-sonnet-4-6)**를 사용한다.

## 맥락

- Alpha(INTJ), Beta(ISFJ) 각 페르소나가 일관된 성격을 유지해야 함
- 시스템 프롬프트로 페르소나를 주입하는 방식 사용
- 응답 품질과 한국어 자연스러움이 중요

## 선택지

| 옵션 | 장점 | 단점 |
|------|------|------|
| **Claude sonnet-4-6** | 한국어 품질 우수, 시스템 프롬프트 준수율 높음 | API 비용 발생 |
| GPT-4o | 널리 사용됨 | 페르소나 유지 일관성이 상대적으로 낮음 |
| 로컬 LLM (Ollama) | API 비용 없음 | 페르소나 품질 현저히 낮음, 설정 복잡 |

## 근거

- INTJ/ISFJ 페르소나 유지에 Claude가 시스템 프롬프트 준수율이 높음
- `@anthropic-ai/sdk`로 Node.js 환경에서 간단하게 연동 가능
- 한국어 응답 자연스러움

## 트레이드오프

- API 호출 비용 발생 (사용량에 따라 월 $5~$30 예상)
- 인터넷 연결 필수 (오프라인 동작 불가)
- 향후 온디바이스 모델(FoundationModels)로 일부 대체 검토 가능
