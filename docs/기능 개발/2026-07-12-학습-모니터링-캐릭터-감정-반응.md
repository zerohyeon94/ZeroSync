# 학습 모니터링 + 캐릭터 감정 반응 (설계)

날짜: 2026-07-12
상태: 설계 승인 완료, 구현 전

## Executive Summary

- 한 줄 소개: 데스크톱을 돌아다니는 알파·베타가 사용자의 활동(코딩/유튜브)을 감지해 감정으로 반응하고, Obsidian vault 기반으로 학습 진도를 브리핑하는 macOS 학습 동반자
- 타겟 유저: 혼자 공부·개발하며 동기 부여가 필요한 사용자 (1차: 제로 본인)
- 핵심 가치: 감시가 아닌 "동반" — 캐릭터의 감정 반응으로 즐겁게 집중을 유지

## 결정 사항

- 기존 ZeroSync 앱의 확장으로 구현 (별도 앱 아님)
- 활동 감지 수준: 앱 이름 + 창 제목 (손쉬운 사용 권한 1회 필요)
- 진도 분석 대상: Obsidian vault 노트
- 캐릭터: 메이플스토리 제로 "느낌"의 오리지널 캐릭터로 이름·이미지 교체 예정 (넥슨 IP 미사용, 배포 가능)
- 아키텍처: 규칙 기반 활동 판정 + 상태 머신 감정 반응 (LLM 상시 판정은 배터리·지연 문제로 배제, 추후 하이브리드 확장)

## 1. 활동 감지 — ActivityMonitor (신규 서비스)

- `NSWorkspace.shared.frontmostApplication`으로 전면 앱 감지 (권한 불필요)
- Accessibility API(`AXUIElement`)로 전면 창 제목 읽기 — 브라우저 창 제목에서 "YouTube" 등 키워드 감지
- 5초 간격 폴링 + `didActivateApplicationNotification` 구독
- 출력 모델: `Activity(app: String, windowTitle: String, category: ActivityCategory)`
  - `ActivityCategory`: `.productive` / `.distraction` / `.neutral`
- 분류 규칙 테이블 (사용자 편집 가능, 설정 화면에서 앱·키워드 추가):
  - 생산: Xcode, Terminal, VS Code, Obsidian 등
  - 딴짓: 창 제목에 YouTube·Netflix 등 키워드 포함
  - 그 외: 중립

## 2. 학습 세션 — StudySessionManager (신규 서비스)

- MVP: 수동 시작 — 메뉴바 또는 캐릭터 클릭으로 학습 모드 시작/종료
- 세션 중 활동 기록을 SwiftData에 저장 (시간대별 생산/딴짓 비율)
- 세션 종료 시 리포트: 총 시간, 집중율, 캐릭터 한 줄 평 (Ollama 생성)
- 확장(2단계): 주간 스케줄 ("평일 20~22시는 학습 시간") → 자동 세션 시작

## 3. 캐릭터 감정 반응 — DesktopPetManager 확장

기존 상태 머신(idle/walking/airborne/dragging)에 감정 레이어 추가.

| 상황 | 알파 (행동파 반항아) | 베타 (외유내강 수호자) |
|---|---|---|
| 학습 중 + 코딩 | 옆에서 같이 코딩하는 모션 | 조용히 응원 팻말 |
| 학습 중 + 유튜브 5분 경과 | 화면 가운데로 달려와 화냄 | 슬픈 표정으로 쳐다봄 |
| 학습 중 + 유튜브 15분 경과 | 화면을 두드리며 항의 | 말풍선으로 부드럽게 설득 |
| 딴짓 후 복귀 | "그럴 줄 알았다" 시니컬 대사 | 기뻐하며 폴짝 |
| 세션 목표 달성 | 파이팅 세리머니 | 축하 말풍선 |

- 말풍선 대사: 페르소나 프롬프트 + Ollama 생성, 실패 시 내장 대사 풀 폴백
- 감정 상태에 따라 이동 패턴 변경 (화나면 사용자 커서 쪽으로 접근 등)

## 4. 진도 분석 — KnowledgeService 확장

- Obsidian vault 최근 수정 노트 스캔 (수정 시각, 신규/수정 구분)
- Ollama에 "이번 주 학습 노트 요약 + 진행 지점" 분석 요청
- 홈 화면 "진행 상황" 카드 + 캐릭터가 브리핑하는 연출

## 5. 캐릭터 리브랜딩

- 알파·베타 이름 유지, 오리지널 디자인 스프라이트 제작 (남녀 듀오 콘셉트)
- PetView에 스프라이트 시트 렌더 경로 추가 (기존 백로그 항목)
- MVP는 현재 벡터 캐릭터에 감정 표현(표정·이펙트)만 추가, 스프라이트는 별도 트랙

## 6. 구현 순서

1. ActivityMonitor + 규칙 분류 (감지 로그만 우선)
2. StudySessionManager + 수동 학습 모드 + SwiftData 기록
3. DesktopPet 감정 레이어 + 반응 행동 + 말풍선
4. 세션 리포트 + vault 진도 분석
5. (확장) 주간 스케줄, 스프라이트 교체, 하이브리드 판정

## 에러 처리·테스트 메모

- 손쉬운 사용 권한 거부 시: 앱 이름만으로 동작하는 축소 모드 + 설정에 권한 안내
- Ollama 미기동 시: 대사·리포트는 내장 텍스트 폴백 (기존 OllamaService 에러 처리 재사용)
- 분류 규칙은 순수 함수로 분리해 단위 테스트 (창 제목 → 카테고리)
- 감정 상태 머신은 입력 이벤트 시퀀스 → 상태 전이 테스트
