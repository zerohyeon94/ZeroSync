# 기능: 페르소나 시스템 (Alpha / Beta)

> Phase 1 핵심 기능 | 상태: 개발 중

---

## 목표

사용자가 Alpha 또는 Beta를 선택하면, 해당 페르소나의 성격에 맞는 시스템 프롬프트가 Claude API에 주입되어 일관된 말투와 성격으로 응답한다.

## 핵심 동작 흐름

```
사용자가 PersonaSelector에서 Alpha 선택
    ↓
alpha-client.ts의 시스템 프롬프트로 API 호출
    ↓
Alpha 말투(단호, 짧게, 사족 없음)로 응답
    ↓
ChatWindow에 표시
```

## 관련 파일

| 파일 | 역할 |
|------|------|
| `src/renderer/src/components/PersonaSelector.tsx` | Alpha/Beta 전환 UI |
| `src/renderer/src/lib/alpha-client.ts` | Alpha 시스템 프롬프트 + API 호출 |
| `src/renderer/src/lib/beta-client.ts` | Beta 시스템 프롬프트 + API 호출 |
| `src/main/ipc.ts` | renderer → main IPC 핸들러 |

## 시스템 프롬프트 원칙

**Alpha (INTJ)**
- 공감, 위로 금지
- 논리/효율/무결성 기반 답변
- 단호하고 짧게. 핵심만.
- 문제점 직접 지적

**Beta (ISFJ)**
- 컨디션/일정 최우선
- 친절하고 다정한 존댓말
- Alpha가 차갑게 말하면 완충
- 번아웃 방지 제안

## 구현 시 주의사항

- Alpha ↔ Beta 전환 시 **각 페르소나의 대화 히스토리는 별도 유지**
- 히스토리가 섞이면 페르소나 혼선 발생 → `storage.ts`에서 페르소나별 분리 저장

## 미결 사항

- [ ] Alpha와 Beta가 동시에 응답하는 "듀얼 모드" 구현 방법
- [ ] 대화 히스토리 최대 길이 제한 (토큰 비용 관리)
