# 데스크톱 캐릭터 (알파·베타 화면 산책)

날짜: 2026-07-09
상태: v1 구현 완료

## 개요

알파(파란 늑대)·베타(흰 북극곰)가 데스크톱 화면 하단을 걸어다니는 마스코트 기능.
에셋 없이 SwiftUI 도형만으로 캐릭터를 그린다 (임의 생성 벡터, 추후 스프라이트 교체 가능).

## 구조

```
AppDelegate ──시작──▶ DesktopPetManager (싱글턴)
                        ├─ 30fps Timer 틱
                        └─ Pet × 2 (알파·베타)
                             ├─ NSPanel (borderless·투명·floating·모든 스페이스)
                             ├─ 상태 머신: idle ↔ walking / airborne / dragging
                             └─ PetVisualState (@Observable) ──▶ PetView (SwiftUI)
```

- `DesktopPet/DesktopPetManager.swift` — 패널 생성, 행동 상태 머신, 물리(점프·낙하)
- `DesktopPet/PetView.swift` — 벡터 캐릭터 드로잉, 걷기·눈 깜빡임 애니메이션(TimelineView)

## 동작

- 걷기: 3~8초 랜덤 방향·속도(40~90pt/s), 화면 가장자리에서 방향 전환
- 대기: 1.5~4.5초 멈춤 후 다시 걷기
- 클릭: 폴짝 점프 (중력 1500pt/s²로 낙하)
- 드래그: 집어서 이동, 공중에서 놓으면 낙하 후 착지
- 설정 → 앱 설정 → "데스크톱 캐릭터 (알파·베타)" 토글로 켜고 끄기 (기본 켜짐)

## 기술 메모

- NSPanel: `.borderless + .nonactivatingPanel`, `backgroundColor = .clear`, `level = .floating`,
  `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .ignoresCycle]`
- 캐릭터 좌우 반전은 `scaleEffect(x: -1)`, 걷기 다리 스윙은 sin(phase) 회전
- SwiftUI 드래그 좌표는 y가 아래로 증가 → 창 좌표로 변환 시 y 부호 반전
- 캐릭터는 `NSScreen.main`(키보드 포커스가 있는 화면)에 스폰됨 — 멀티 모니터에서는
  마지막 포커스 화면에 나타난다

## 개선 아이디어 (백로그)

- 화면 간 이동 (모니터 여러 대를 걸어서 넘어가기)
- 캐릭터 클릭 시 말풍선으로 짧은 반응 대사 (페르소나 말투)
- 캐릭터 더블클릭으로 채팅 창 열기
- 창 위에 올라앉기 (다른 앱 창 상단을 바닥으로 인식)
- 스프라이트 이미지 교체 지원
