# 개선 방향 & 백로그

떠오르는 아이디어, 성능 개선 포인트, 해야 하지만 지금 당장은 아닌 것들.

---

## 백로그 (우선순위 순)

### 높음 — 현재 Phase에서 해결

- [ ] 스트리밍 응답 지원 — API 응답이 완성될 때까지 기다리지 않고 실시간 표시
- [ ] Alpha 코드 블록 렌더링 — `highlight.js` 또는 `shiki` 적용
- [ ] 대화 히스토리 토큰 제한 — 비용 관리를 위한 최대 히스토리 길이 설정
- [ ] 트레이 아이콘 디자인 — Z·A·B 이니셜 삼각형 배치

### 중간 — Phase 2에서 구현

- [ ] 음성 입력 — Web Speech API 기반 STT
- [ ] macOS 시스템 알림 — Beta가 일정 알림 발송
- [ ] Beta 태스크 패널 — 할 일 목록 UI (electron-store 연동)
- [ ] 설정 패널 — API 키 입력, 페르소나 프롬프트 커스터마이징

### 낮음 — Phase 3 이후 검토

- [ ] Alpha+Beta 동시 응답 (듀얼 모드)
- [ ] 화면 캡처 컨텍스트 인식 — 현재 작업 화면을 AI가 인식
- [ ] Tauri 마이그레이션 검토 — 앱 크기, 메모리 최적화
- [ ] FoundationModels 연동 — 온디바이스 LLM으로 오프라인 지원

## 아이디어 메모

개발하다가 떠오른 것들. 실현 가능성 검토 전 상태.

- **Zero의 목소리**: Beta와 대화할 때 TTS(Text-to-Speech)로 음성 응답 지원 가능한지?
- **컨디션 트래킹**: Beta가 매일 컨디션 체크인을 유도하고 주간 패턴 분석
- **Alpha 코드 실행**: Alpha의 코드 응답을 직접 터미널에서 실행하는 기능
- **Manus 에이전트 연동**: 웹 자동화 작업 위임 (Phase 3)
