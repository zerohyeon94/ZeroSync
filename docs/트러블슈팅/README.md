# 트러블슈팅

개발 중 발생한 문제와 해결 과정을 기록한다.
해결됐든 안 됐든 일단 기록하는 것이 원칙.

---

## 작성 형식

```
파일명: [날짜]-[짧은 문제 설명].md
예: 2026-04-29-IPC-응답없음.md
```

각 파일 구성:
1. **증상** — 어떤 현상이 나타났는가
2. **원인** — 왜 발생했는가
3. **해결** — 어떻게 고쳤는가
4. **재발 방지** — 앞으로 어떻게 막을 것인가
