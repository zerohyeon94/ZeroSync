# 학습 세션 MVP 한계

Phase 2 StudySessionManager 코드 리뷰에서 확인된 의도적 MVP 한계. 추후 개선 시 참고.

## 1. 앱 강제 종료 시 진행 중 세션 유실

- `endSession()`에서만 `save()`를 호출하므로, 앱이 강제 종료되면 진행 중 세션의 누적 시간이 유실된다.
- `endedAt`이 nil인 고아 세션은 `loadLastSession()`에서 복원되지 않는다 (완료된 세션만 조회).
- 개선 방향: 주기적 저장(예: 틱마다 또는 1분마다) 또는 앱 시작 시 고아 세션 정리 로직 추가.

## 2. save 실패가 조용히 무시됨

- `endSession()`의 `try? context?.save()`가 실패해도 아무 기록이 남지 않는다.
- 개선 방향: 저장 실패 시 로깅 추가.

## 3. 관측 없는 구간은 어떤 카테고리에도 계상 안 됨

- `tick()`에서 `monitor.current`가 nil이면 해당 구간(dt)을 버린다.
- 그 결과 `totalSeconds > 카테고리 합`이 될 수 있다 — 의도된 결정 (관측 못한 시간을 임의 카테고리에 넣지 않음).
- 리포트 UI에서 카테고리 합과 총 시간의 차이를 "미관측"으로 표시할지 추후 판단.
