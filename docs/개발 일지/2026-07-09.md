## 막힌 것 / 발견한 것

- SwiftUI `foregroundStyle` 삼항에서 `.secondary : .red` 혼용 시 HierarchicalShapeStyle/Color 타입 불일치 컴파일 오류 → `Color.secondary : Color.red`로 명시
- 문자열 검색 시 `lowercased()` 문자열의 String.Index를 원본에 쓰면 안 됨 → `.caseInsensitive` 옵션으로 원본 기준 검색으로 수정
- SourceKit이 새 파일 추가 후 기존 타입까지 못 찾는 진단을 내는데 실제 빌드는 정상 (인덱스 지연)
- Ollama가 아직 이 Mac에 설치돼 있지 않음 → 실행 전 설치 필요
- `NSScreen.main`은 "주 모니터"가 아니라 "키보드 포커스가 있는 화면" — 멀티 모니터에서
  캐릭터가 포커스된 화면에 스폰됨. 이미 실행 중인 앱에 `open`을 하면 새 빌드가 아닌
  기존 인스턴스만 활성화되므로 재실행 시 pkill 필요
