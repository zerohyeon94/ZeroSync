## 막힌 것 / 발견한 것

- 연결 하나를 여러 코루틴이 함께 쓰므로 저장소 트랜잭션은 `asyncio.Lock`으로 순서를 지킴. 같은 작업에 `/decide`가 동시에 두 번 와도 하나만 반영됨을 테스트로 확인
- `executescript`는 시작 전에 열린 트랜잭션을 커밋하므로, 마이그레이션 SQL 안에 BEGIN/COMMIT을 직접 넣어 버전 기록과 묶음

- 이 맥에 `claude`, `codex` CLI가 없어 SPEC V1~V3(출력 옵션, 권한 옵션)을 확인할 수 없음. CLI 러너는 설치 후 `feat/0-cli-runners`로 분리 (SPEC 12.2 갱신)
- 테스트는 pytest-asyncio 없이 `asyncio.run`으로 작성. 의존성을 늘리지 않기 위해서이며, 비동기 테스트가 많아지면 다시 검토
- 출력을 읽는 쪽은 프로세스 종료 뒤 최대 유예 시간(기본 5초)만 기다림. 종료된 프로세스의 출력 파이프를 다른 프로세스가 붙잡고 있어도 실행이 끝나지 않는 일을 막기 위해서
- 실행 로그에 프롬프트를 포함한 전체 인자가 남음. 토큰 마스킹(SPEC 9.5 [제안])은 아직 없음
- Xcode 빌드(SPEC V9)는 여전히 CoreDevice 라이브러리 로드 오류로 보류

- pydantic은 기본값을 검증하지 않아 `~/.zerosync/...` 기본 경로가 펼쳐지지 않았음. 설정 모델에 `validate_default=True`를 켜서 해결
