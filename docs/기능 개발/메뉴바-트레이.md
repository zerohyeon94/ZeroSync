# 기능: macOS 메뉴바 트레이

> Phase 1 | 상태: 기본 구현 완료

---

## 목표

macOS 메뉴바에 Z.A.B 아이콘이 상주하고, 클릭 시 채팅 팝업이 나타난다.
앱을 "닫아도" 트레이에 남아있어야 한다.

## 관련 파일

| 파일 | 역할 |
|------|------|
| `src/main/index.ts` | BrowserWindow 생성, 팝업 위치 제어 |
| `resources/` | 트레이 아이콘 이미지 |

## 핵심 동작

```typescript
// 트레이 클릭 → 팝업 토글
tray.on('click', () => {
  if (win.isVisible()) {
    win.hide()
  } else {
    // 트레이 아이콘 바로 아래에 팝업 위치
    const { x, y } = tray.getBounds()
    win.setPosition(x, y)
    win.show()
  }
})

// 창 닫기 버튼 → 트레이에 남김 (앱 종료 아님)
win.on('close', (e) => {
  e.preventDefault()
  win.hide()
})
```

## 구현 시 주의사항

- macOS에서 `win.setPosition()` 좌표계가 화면 해상도에 따라 달라짐
- 멀티 모니터 환경에서 트레이 위치 계산 주의
- `app.dock.hide()`로 Dock에 아이콘 표시 안 하도록 설정
