## 막힌 것 / 발견한 것

- `claude --bare`는 OAuth·키체인을 읽지 않아 구독 로그인과 함께 쓸 수 없음. 대신 `--strict-mcp-config`로 사용자 MCP 서버만 끔
- `--permission-prompts none`이어도 `ls` 같은 읽기 전용 Bash 명령은 허용 목록 없이 실행됨. 쓰기·원격 명령은 거부됨
- 신뢰 처리하지 않은 임시 폴더에서도 `claude -p`, `codex exec`가 질문 없이 실행됨. SPEC 9.4의 "폴더 신뢰 처리"가 필요한지 실제 앱 저장소에서 다시 확인
- 이 계정의 Claude 기본 모델은 Opus 5.5라 Pro 사용량을 빨리 씀. 단계별 모델 설정으로 의견 단계는 sonnet을 쓰게 함
- Codex 기본 모델은 `--ignore-user-config` 상태에서 CLI 기본값을 따름 (시험 호출 시 stderr에 표시)
- Claude 결과 JSON의 `permission_denials`는 아직 `AgentResult`에 담지 않음. 실행 로그에는 원문이 남음. 구현 단계 엔진에서 필요하면 추가
- Homebrew 설치 중 Command Line Tools가 오래됐다는 오류(`pkgconf` 재설치 실패)가 나옴. CLI 설치에는 영향 없음. Xcode 작업 전에 업데이트 필요
