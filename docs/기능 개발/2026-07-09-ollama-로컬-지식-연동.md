# Ollama 로컬 LLM 전환 + 로컬 지식(Obsidian·Developer) 연동

날짜: 2026-07-09
상태: Phase 1 구현
브랜치: docs/swift-swiftui-migration

## 목표

1. Claude API를 완전히 제거하고 Ollama 로컬 LLM으로 알파·베타 대화를 구동한다 (API 비용 제로).
2. Obsidian vault(`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/zerohyeon-labs`)의 md 문서를 대화 컨텍스트로 활용한다.
3. `~/Developer`의 프로젝트 현황(구조 + README·CLAUDE.md·docs 문서)을 파악해 대화에 활용한다.

## 결정 사항 (사용자 확인 완료)

| 항목 | 결정 |
|---|---|
| Ollama 역할 | Claude 완전 대체 (기존 ClaudeService 삭제) |
| 지식 활용 방식 | Phase 1: 키워드 검색 주입 → Phase 2: 임베딩 RAG (bge-m3) |
| Developer 파악 범위 | 구조 + 문서만 (README, CLAUDE.md, AGENTS.md, docs/*.md) |
| 검색-주입 아키텍처 | 사전 검색 주입 (툴 콜링 미사용 — 로컬 모델 안정성) |
| 샌드박스 | 유지. 보안 범위 북마크(security-scoped bookmark)로 폴더 접근 |
| 기본 모델 | qwen3:14b (M3 Pro 36GB 기준 한국어 품질·속도 균형), 설정에서 변경 가능 |

## 아키텍처

```
사용자 메시지
   │
   ▼
ChatViewModel.send
   │
   ├─ KnowledgeService.buildContext(query)   ← 백그라운드(nonisolated)
   │     ├─ WorkspaceAccess로 북마크 폴더 접근
   │     ├─ vault: 재귀 *.md 스캔 (.obsidian, .trash, Templates 제외)
   │     ├─ developer: 프로젝트 목록 + 문서 파일만
   │     ├─ 키워드 추출 → 파일명/내용 점수화 → 상위 4개 스니펫
   │     └─ 작업 공간 개요(폴더·프로젝트 목록) + 스니펫 블록 반환
   │
   ▼
OllamaService.send(history, persona, knowledge)
   │   POST http://localhost:11434/api/chat (stream: false)
   │   system = persona.systemPrompt + [참고 자료] 블록
   │   응답의 <think>...</think> 블록 제거 (qwen3 등 추론 모델 대응)
   ▼
알파·베타 응답 (기존과 동일하게 동시 요청)
```

## 컴포넌트

### OllamaService (Services/OllamaService.swift)
- `send(history:persona:knowledge:)` — /api/chat 단발 호출, 응답 문자열 반환
- `listModels()` — GET /api/tags, 설정 화면 상태 표시·모델 선택용
- 모델명: `UserDefaults "ollamaModel"`, 기본 `qwen3:14b`
- 오류: 서버 미실행(연결 거부) → 설치·실행 안내, 모델 없음(404) → `ollama pull` 안내

### WorkspaceAccess (Services/WorkspaceAccess.swift)
- `KnowledgeFolder` enum: `.vault`, `.developer`
- `pickFolder(_:)` — NSOpenPanel로 폴더 선택, `.withSecurityScope` 북마크를 UserDefaults에 저장
- `resolveURL(for:)` — 북마크 복원(만료 시 갱신), 호출부에서 start/stopAccessing 쌍으로 사용
- entitlements 추가: `files.user-selected.read-only`, `files.bookmarks.app-scope`

### KnowledgeService (Services/KnowledgeService.swift)
- `nonisolated` — 메인 액터 밖에서 실행
- 키워드 추출: 한글·영숫자 토큰화, 2자 미만·불용어 제거, 한국어 조사 접미 제거 휴리스틱
- 2단계 점수화: ① 파일명·경로 매칭 ② 파일명 매칭 파일 + 최근 수정 상위 파일만 내용 스캔(파일당 최대 64KB)
- 스니펫: 첫 매칭 위치 주변 약 1,200자, 총 주입 상한 약 6,000자
- 매칭이 없어도 작업 공간 개요(vault 최상위 폴더 + Developer 프로젝트 목록)는 항상 포함

### 변경되는 기존 코드
- `ChatViewModel.send` — ClaudeService → KnowledgeService + OllamaService
- `MainView` — API 키 섹션 삭제 → Ollama 상태·모델 섹션 + 로컬 지식 폴더 섹션 추가
- `ClaudeService.swift` 삭제, CLAUDE.md 기술 스택 갱신

## 오류 처리
- Ollama 미실행: "Ollama가 실행 중이 아닙니다..." 안내 (설치 URL + pull 명령)
- 폴더 미연결: 지식 컨텍스트 없이 대화만 진행 (개요 블록 생략)
- 북마크 만료: 자동 갱신 시도, 실패 시 설정에서 재선택 유도

## Phase 2 (임베딩 RAG — 이후 작업)
- 임베딩 모델: `bge-m3` (한국어 강함), Ollama `/api/embed`
- md 파일을 500~800자 청크로 분할, 벡터 인덱스를 Application Support에 캐시
- 파일 수정일 기반 증분 재인덱싱
- `KnowledgeService`의 검색 단계만 벡터 유사도 검색으로 교체 (주입 파이프라인 동일)

## 사전 준비 (사용자)
```
brew install ollama        # 또는 https://ollama.com 앱 설치
ollama serve               # 앱 설치 시 자동 실행
ollama pull qwen3:14b
```
