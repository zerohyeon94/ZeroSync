# 기능: macOS 메뉴바 트레이

> Phase 1 | 상태: 기본 구현 완료

---

## 목표

macOS 메뉴바에 Z.A.B 아이콘이 상주하고, 클릭 시 채팅 팝업이 나타난다.
앱을 "닫아도" 메뉴바에 남아있어야 하며 Dock 아이콘은 표시하지 않는다.

## 관련 파일

| 파일 | 역할 |
|------|------|
| `ZeroSync/ZeroSyncApp.swift` | `MenuBarExtra` 선언, `WindowGroup` 설정 |
| `ZeroSync/Views/MenuBarView.swift` | 메뉴바 팝업 콘텐츠 뷰 |
| `ZeroSync/AppDelegate.swift` | `NSApplicationDelegate` — Dock 아이콘 숨김 처리 |

## 핵심 동작

```swift
// ZeroSyncApp.swift
@main
struct ZeroSyncApp: App {
    @NSApplicationDelegateAdaptor(AppDelegate.self) var appDelegate

    var body: some Scene {
        // 메뉴바 아이콘 — 클릭 시 팝업 토글
        MenuBarExtra("ZeroSync", systemImage: "clock.arrow.2.circlepath") {
            MenuBarView()
        }
        .menuBarExtraStyle(.window)  // 팝업 윈도우 스타일
    }
}

// AppDelegate.swift
class AppDelegate: NSObject, NSApplicationDelegate {
    func applicationDidFinishLaunching(_ notification: Notification) {
        // Dock 아이콘 숨김
        NSApp.setActivationPolicy(.accessory)
    }
}
```

## 구현 시 주의사항

- `MenuBarExtra`는 macOS 13+ 전용 — 최소 배포 타겟을 macOS 13 이상으로 설정
- `.menuBarExtraStyle(.window)` : 채팅 팝업처럼 커스텀 뷰를 띄울 때 사용
- `.menuBarExtraStyle(.menu)` : 기본 드롭다운 메뉴 스타일 (채팅 UI에는 부적합)
- `NSApp.setActivationPolicy(.accessory)` 로 Dock 아이콘 및 앱 전환기에서 제거
- 팝업 창 크기는 `MenuBarView` 내부에서 `.frame(width:height:)`으로 고정

## 미결 사항

- [ ] 트레이 아이콘 디자인 (Z·A·B 이니셜 삼각형 배치) — 커스텀 SF Symbol 또는 이미지 에셋
- [ ] 우클릭 컨텍스트 메뉴 (종료, 설정 등) — `MenuBarExtra` 내 Button 추가
- [ ] 팝업 창 최적 크기 결정
